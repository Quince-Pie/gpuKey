Color, producer and quantizer audit — 23 October 2026 UTC

Delivered changes
- FFmpeg AV1 VAAPI rejects unsupported zero-QIndex pictures during setup and
  selects the required inferred ONLY_4X4 mode for a supported zero-QIndex header.
- Vulkan rejects explicitly unsupported QIndex requests instead of silently
  clamping them, and constrains derived picture quantizers to the device range.
- The standalone RGB probe supports a uniform color cube and waits for DMA-BUF
  producer writes before cross-API encoding. The actual recorder already waited.
- Independent streamed cube generator/analyzer and updated memory/source audit.
- No new default backend, color profile, memory limit or timing policy.

Excluded exploration and failures
- Initial cube-* direct-RGB and full-cube-{limited,full} results omitted the
  DMA-BUF producer wait. They are retained, not used for final color conclusions.
- native-quantizer-matrix/control and queue disagree: the producer sometimes
  supplied the previous contents of a reused surface. The fixed recorder's event
  loop already waits on that producer dependency. The standalone test is repaired.
- quantizer-build.log: first patch used an incorrect FFmpeg enum spelling;
  quantizer-fixed-build.log records the corrected successful build.
- native-quantizer-check.log: direct invocation of a nonexecutable script failed;
  subsequent checks explicitly use Bash.
- rgb-clang-build.log: the requested target mistakenly named clang-mold in the
  clang shell. The correct clang target succeeds; this is not a compiler failure.

  the firmware-supported BT.2020/full pair, not unsupported cross-pairs.

- Installed Niri source bazsf2g3j9imcrqrw18p3zn9911s7lfm offers RGB only. The

- No timing, RAM or VRAM performance claim is made from these diagnostic runs;

  and no user process or compositor was changed. The broader goal remains active.

Reproduce the usable recorder
  nix run .#rgb-amd -- replay 30 --display --fps 60 --backend vulkan --device 0
  nix run .#amd -- replay 30 --display --fps 60
  nix develop .#rgb -c bash /tmp/gpukey-color/run-fenced-cubes.sh
  nix develop .#rgb -c bash /tmp/gpukey-color/run-fenced-equivalence.sh

The diagnostic scripts intentionally require fresh output destinations. Preserve
existing evidence and select new names when rerunning. The final decoder oracle
and corpus generator are tools/analyze-color-cube.py and generate-color-cube.py.
