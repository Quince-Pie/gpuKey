Mechanisms and lifecycle
- Trace elimination uses the same CQP predicate as the offset consumer.
- Direct serialization uses the existing syntax writer. Sequence state becomes
  owned before raw input can expire; references are released on all outcomes.
- VAAPI opts out of unused redundant-header bits, preserving ordinary CBS use.
- Raw OBUs are call-local. Coded bytes and compact metadata payloads persist.
- Generic writer rollback storage remains. Its removal is not part of this result.
- layout.log records inspected type sizes/offsets. The 17,160-byte context
  reduction is derived from those layouts, not measured process RSS.
- A 1 MiB encoder write-buffer reservation disappears, but first-picture
  parsing/allocator/page-commit costs remain. Do not claim a 1 MiB RSS saving.
