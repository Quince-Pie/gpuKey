Idle coded-output reclamation and Vulkan pool ownership — 24 October 2026 UTC

Implemented behavior
- --gpu-memory compact supports VAAPI and Vulkan. Retain remains the default.
- Active compact capture keeps at most one unused coded-output buffer. An eligible
  static independent-key cache transition releases all unused coded-output buffers;
  new input restores the one-spare policy. Capacity, AV1 state and quality stay intact.
- Vulkan upload-image capacity is preserved to avoid repeated image allocation.
- Vulkan pooled buffers own a device reference and three destruction callbacks,
  shared once per pool. They no longer dereference a destroyed encoder/filter context.
- Fatal video API errors are latched separately from capture/mux failure. A failed
  codec receives no more encode/drain calls; collected output is finalized and the
  original error is returned. Capture/input failures still drain valid accepted work.
- The error flag fits existing padding: the x86-64 media object remains 2,280 bytes.
  The pool owner is 32 bytes plus a 24-byte AVBufferRef, not a per-packet cost.

Retained test-harness failures
- The first owner repair assumed every FFVulkanContext carried device_ref directly;
  actual encoder/transfer contexts differ. The corrected helper takes explicit
  ownership from each caller. owner-assumed-context.patch preserves the rejected form.
- A preload-only second-pool fault never fired due to internal symbolic binding.
  Debugger injection reaches the staging and encoder constructors independently.
- The first validation run selected the system ICD; pinned patched-driver runs pass.
- The first static Samply attempt used a moving-source oracle and rejected correct
  static playback. samply-frozen uses the explicit static fixture mode.
- Tracy's first wrapper named a nonexistent build directory. tracy-corrected and
  tracy-frozen use the actual gcc-release-tracy-rgb binary.
- The first BO fault helper lacked a global libdrm dependency; the linked helper
  and final phase-armed helper retain that dependency explicitly.

Scope
- GTT, RSS, VRAM, shared producer storage and sampled peaks are separate quantities.
  Static recorder-visible VRAM can include one import while the producer owns two.
- Zero unused coded buffers is an idle target, not a smaller active output buffer.
  The full 3*coded_width*coded_height+65536 capacity is restored on demand.
- Profiling zones are observations, not a pure-GPU or end-to-end latency theorem.
- The broader goal remains active; no every-metric or universal SOTA claim is made.

Use
  nix run .#amd -- replay 30 --display --fps 60 --static-interval 2 --gpu-memory compact
  nix run .#rgb-amd -- replay 30 --display --fps 60 --backend vulkan --device 0 --static-interval 2 --gpu-memory compact
  gpukey save

Retain remains the default for users who prefer keeping output allocation ready.
The archived scripts require fresh output names. No live compositor, desktop
shortcut, browser profile or kernel profiling policy was changed.
