Static raw-input retirement checkpoint — 24 October 2026 UTC

Behavior
- Independent static refreshes are declared from the configured two-second-or-
  longer cadence. Default one-second refinement and prior internal callers stay
  compatible. Shorter requests in explicit independent mode still produce keys.
- Compact standby begins only after accepted input is fully collected and an
  independent CPU key has been validated and committed. A newer real input
  cancels the pending transition. Prepared input is protected.
- Vulkan files replace the pending mapped packet with identical CPU-owned data
  and properties before trimming. Replay retains its existing CPU payload.
- VAAPI releases the last completed converted input; direct RGB releases the
  last source pin and promptly returns the capture lease. Cached imports and
  live codec references remain. Input capacity restores on the next preparation.
- Optional cache-setup failure retains raw fallback. Later key publication
  failure after retirement stops with an error and preserves the completed prefix.
- Both flags fit padding: media/options stay 2,280/192 bytes on x86-64.
