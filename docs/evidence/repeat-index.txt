Independent static-key reuse and replay export compaction — 24 October 2026 UTC

Delivered artifact
- Eligible independent AV1 refreshes reuse the encoded key only while no new
  encoder input has intervened and all earlier encoder output is collected.
- --static-interval 2 enables this case; the one-second default is unchanged.
  --static-encoding always retains ordinary encoding at the selected cadence.
- Actual encoder outputs and reused samples have separate counters. Allocation
  failure falls back to encoding; the last raw image remains available.
- Replay borrows its existing CPU key payload. Vulkan file recording copies one
  encoded key instead of pinning a much larger GPU output allocation.
- Export compacts consecutive byte-identical independent keys in its flat index
  and retains a terminal sample. Dependent pictures and image changes remain.
- Long MP4 holds retain checkpoints for movenc's signed INT_MAX duration limit.
- The 32-byte live packet record and the GPU image plan are unchanged.

Rejected mechanisms and limits
- Replaying a displayed key through show_existing_frame violates AV1 showability.
  dav1d tolerates the invalid probe; libaom rejects it. The recorder emits no such
  shortcut. invalid-libaom.log and invalid-show-existing.mkv retain the evidence.
- A pure one-picture 30-second hold decodes but reaches EOS immediately in Brave.
  A terminal independent sample repairs the tested consumer behavior, at the cost
  of one extra payload for a one-picture clip. Longer runs remove duplicate bytes.
- Native I/P encodes of an unchanged source produce three reconstructions. Reuse
  therefore replaces only requested independent refreshes, not refining P-frames.
- The initial MP4 consumer harness requested .mkv save paths. The recorder rejected
  their container mismatch; native-mp4-final/ preserves that test-harness failure.
  Corrected scripts use .mp4 names and leave application suffix checks intact.
- The goal remains active. These are static-workload improvements, not universal
  optimality, a moving-scene compression theorem, or an every-metric SOTA result.

The archived scripts require fresh output names. Browser tests use private
profiles, anonymous debugging pipes and a loopback HTTP server; they do not
establish ordinary accelerated desktop-player behavior. See docs/validation.md
and docs/memory-targets.md for complete measurements and conditional targets.
