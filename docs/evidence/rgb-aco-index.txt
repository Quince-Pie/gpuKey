Exploration retained but excluded from final timing claims
- comparison/ is the initial partial timing series. The hash gate detected an
  observer-source edit during a run. confirmation/ restarted with frozen inputs.
- caps-check.log records a manual compile missing the normal GNU feature flags.
  The corrected check uses the repository Makefile and passes.
- RAM samples are mapping walks, can race mapping changes, and depend on sharing

Reproduce
  nix run .#rgb-amd -- replay 30 --display --fps 60 --backend vulkan --device 0
  nix build .#mesa-rgb-reference
  nix flake check

Exact native/comparison/profiling commands are preserved in run-confirmation.sh,
run-confirmation-tail.sh, recorder wrappers, and per-run record scripts. The new
--smaps-after option is enabled by GPUKEY_RECORDER_SMAPS_AFTER in the comparison
launcher. Every capture is a private fixture, not a user's desktop/process.

Scope
RAM improves without changing tested encoded output. CPU relative to the old
Vulkan build is mixed, and latency traces do not establish a gain. RGB color
precision still differs from VAAPI; full-scene rate-distortion, game interference,
energy, other hardware and full source-to-packet latency remain unverified. The
conditional 87.890625 MiB image target is unchanged. The broader goal stays active.
