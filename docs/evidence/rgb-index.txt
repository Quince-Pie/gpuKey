Exploration and failures are retained
- Earlier comparison/, package-comparison/, final-comparison/ and replay variants
  predate final lifetime/layout fixes. Some used a development build. They are
  not the final candidate's performance evidence.
- Initial BGRA views swapped channels; later native views corrected them.
- Rate-control, initial-layout, view/output-buffer/CBS cleanup and failed-picture
  unlinking errors were found and fixed. A 256-byte driver-unload leak report is
  retained separately from the fixed FFmpeg leak.
- Reducing video-session slot reservation did not reduce measured VRAM. Repeated
  80 KiB allocations were command buffers, not per-slot CDF allocations.
- Some harness attempts inherited benchmark-only variables or used a mismatched
  file extension; those failed before exercising the intended recorder path.
- A preload aimed at a /usr/bin/env wrapper hit the host's older glibc. The final
  API tracer selects the backend while launching the Nix ELF directly.
- A patch-generation assertion failed before writing its target; its correction
  and the resulting rebuild are retained. No such failure is called a pass.

Remaining scope
The default remains VAAPI. Direct RGB saves VRAM but uses more RSS, has slightly
higher constant-patch error, longer source leases, and mixed portrait CPU results.
A single long replay pair is not a universal win. Full-scene rate-distortion,
game interference, energy, complete source-to-packet latency and other hardware
remain unverified. The active goal continues. Initial DPB transition ownership,
minimal video-only device construction and VA encode-time RGB processing remain
open alternatives. No state-of-the-art-on-every-metric claim is made.
